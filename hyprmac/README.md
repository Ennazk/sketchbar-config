# HyprMac config

Copies of `~/Library/Application Support/HyprMac/`:

- `config.json`: keybinds, Hypr key (left Option), gaps, scratchpad settings
- `monitor-config.json`: per-Mac settings, including the status export that feeds the SketchyBar workspace numbers (`items/hyprmac_spaces.sh`)

To restore, quit HyprMac, copy both files back, and reopen it.
